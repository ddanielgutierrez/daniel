Journey Through the Universe

This project is an interactive animation that visualizes the size of structures in the universe, ranging from the Planck length to the observable universe.

To run:
In the terminal, run "python final_project.py"

To move to the NEXT BIGGEST object: Press the right arrow
To move to the NEXT SMALLEST object: Press the left arrow
To see the next fun fact, press "n" or "p"
